# G2: The Range — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In solo play, stand dummies and steel plates in front of the spawn bay. Dummies take a match's damage, fall and stand again; plates ring and show where they were struck. A readout says what each hit did.

**Architecture:**
- **The range's rules** are pure: `src/combat/range.ts` holds the layout over the world, the dummies' health and timers, the movers' paths and the plates' voxels.
- **The app's half** (`src/app/range.ts`) writes the plates into the world, poses the dummies as soldiers (the renderer's 8 slots), and hands them to the session as `targets`. Those are bodies only the player's rounds strike. It reads the frame's hits and impacts, and drives the HUD's readout.
- **When it stands:** solo play, from the click that starts play. Never in a room, in a check run, or with `?range=0`. In e2e only when a test asks.

**Tech Stack:** TypeScript, WebGPU, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-03-trenchline-shots-design.md` §5 (and §4 for what G3 later adds to hits).

## Global Constraints

- **Pure code:** `src/combat`, `src/world` and `src/sim` follow `tests/architecture.test.ts`. They use `core/dmath`, with no DOM, time or `Math.*` transcendentals.
- **Numbers** live in `data/tunables.toml`, under a new `[range]` table.
- **Damage:** a dummy takes `gunDamage(DAMAGE[zone], gun)` (`src/net/gear.ts`, `src/net/match-rules.ts`). It has 100 HP. Health comes back as the match rules' does (`REGEN_DELAY_MS`, `REGEN_PER_S`; export them from match-rules if they are not exported). It is down 4 s.
- **Where things stand:**
  - dummies at 25, 40, 60, 80, 110 and 150 m;
  - movers at 50 and 90 m, walking 1.4 m/s over 8 m;
  - torso plates (0.45 × 0.6 m) at 30, 55 and 85 m;
  - head plates (0.25 × 0.3 m) at 45 and 70 m;
  - each across the bay's frontage within ±12 m;
  - a blocked spot moves up to 3 m sideways.
- **Palette:** new entries are appended after id 79, with no renumbering:
  - TARGET_STEEL, white-painted steel, kind HULL;
  - TARGET_STEEL_HIT, a lead-grey splash, kind HULL;
  - TAPE_RANGE, hunter orange, kind CLOTH, with emission as the other tapes.

  A round's `chip` must leave both target steels as they are.
- **Body ids:** dummies' are 200 + index (never 0–7, a match's seats; never −1, the player's own).
- **Commits:** branch `shots`, never pushed. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Quiet e2e:** no other e2e run may be going.

## Review Focus

- **The front's rounds in solo with the range up:** they must pass through dummies, and must not stop at the player's body (solo has no health). Today a body test runs only with friends. Task 1 pins both.
- **A plate written where the player stands, or into a trench:** the layout must never put a plate or a dummy in a trench, in water or within 2 m of the spawn bay's parapet. Task 2 tests both maps.
- **The range taken down** (joining a room, `hooks.range(false)`): every voxel the plates wrote must be restored exactly. Task 3 tests the map against a snapshot.
- **Rapid hits on a falling dummy:** rounds into a dummy that is already down score nothing, and the readout does not show a second kill. Task 2 tests it.
- **A shotgun's nine pellets into one dummy on one tick:** the hits are summed in order, the kill comes once, and the readout gives the shot count, not the pellet count. Task 2 tests it.

- Produces:
```ts
export interface RangeTunables { /* the [range] table */ }
export function rangeTunables(tun: Tunables): RangeTunables;
export interface RangeSpot { kind: 'dummy' | 'mover' | 'torso' | 'head'; at: [number, number, number]; distanceM: number }
/** Spots out along the bay's facing from `spawn`, on dry, level ground; a blocked one moved sideways (0, +0.5, −0.5, +1 … ±shift_m); none if every try is blocked. */
export function rangeLayout(map: BrickMap, voxel: number, spawn: { position: readonly [number, number, number]; bay: { longAxis: 0 | 2; facing: 1 | -1 } }, t: RangeTunables): RangeSpot[];
/** The voxels a plate and its post are: [x, y, z, palette] in voxels. */
export function plateVoxels(spot: RangeSpot, voxel: number, t: RangeTunables, facing: { longAxis: 0 | 2; facing: 1 | -1 }): [number, number, number, number][];
export type RangeEvent =
  | { kind: 'hit'; id: number; zone: Zone; damage: number; distanceM: number }
  | { kind: 'kill'; id: number; zone: Zone; damage: number; distanceM: number; shots: number }
  | { kind: 'plate'; index: number; distanceM: number };
export class Range {
  constructor(spots: readonly RangeSpot[], t: RangeTunables, bay: { longAxis: 0 | 2; facing: 1 | -1 });
  /** The dummies (static first, then movers) as figures at `nowS`: id 200 + i, where, how fast, facing, seconds down (null standing). */
  figures(nowS: number): { id: number; position: [number, number, number]; velocity: [number, number, number]; yaw: number; deadFor: number | null }[];
  /** A round of the player's into dummy `id`; `shot` counts the trigger's shots, so a shotgun's pellets are one shot. */
  hit(id: number, zone: Zone, gun: number | undefined, distanceM: number, shot: number, nowS: number): RangeEvent | null;
  plate(index: number, distanceM: number): RangeEvent;
  step(nowS: number): void;
}
```

### Task 3: The range in the app

**Files:**
- Create: `src/app/range.ts`:
  - `class RangeView`;
  - `raise(session: Session, spawn)`: lays out, writes the plates while keeping what they replaced, and makes a `Range`;
  - `lower(session)`: restores every voxel exactly;
  - `frame(session, gaits: Gaits, dt, nowS): Figure[]`: the dummies as `Figure`s, `team: 'blue'`, `tape: P.TAPE_RANGE`, gear 0. It poses them and sets `session.targets`;
  - `after(events: CombatEvents, nowS): RangeEvent[]`:
    - consumes `events.hits` with owner 0 and body ≥ 200, counting shots by `events.shots`' ticks;
    - consumes `events.impacts` with owner 0 whose material is a target steel: a plate event, and the struck voxel repainted `TARGET_STEEL_HIT`;
  - `get up(): boolean`; `state()`: for the hooks.
- Modify: `src/app/main.ts`:
  - a `RangeView`;
  - **allowed** when `rangeAllowed({ room: together.net !== null, check: checkRun, param: searchParams.get('range') })` is true. That is a pure function exported from `src/app/range.ts`;
  - **raised** at the first `play()` in solo when allowed, and lowered when a room is joined;
  - **each frame:** its figures go in with the puppets to `together.prepare` (so the soldiers draw them), and `after()` runs after the ticks;
  - the readout is shown from its events;
  - **hooks:** `range(on: boolean)` (sets allowed, and raises or lowers at once if playing) and `rangeState()`, giving `{ up, dummies: [{ id, position, hp, down }], plates: [{ index, at, hits }], readout }`.
