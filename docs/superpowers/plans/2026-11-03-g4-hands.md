# G4: The Gun in the Hands — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the gun in the hands move as a held gun does: bob, sway, breathe, swing to a sprint, dip on landing, work through its reload and pump, click when empty. And make each shot's flash and smoke worth looking at.

**Architecture:**
- **The motion** is one new pure module, `src/combat/handling.ts`. Its state is ticked by the session, so the drawn muzzle (tracers and flash) is the posed one. It gives a pose delta that `heldPose` adds, kept before and after each tick for interpolation, as the view kick is.
- **The session** gains the sprint-to-fire rule, the dry trigger, and the shotgun's shell-by-shell reload time (`weapon.ts`). It sends handling cues (mag out, mag in, bolt, shell, pump, dry) as events for the audio plan.
- **The flash** is rebuilt in `effects-frame.ts`: a core billboard and prongs at random per shot. The smoke is a new particle kind emitted by the session.

**Tech Stack:** TypeScript, WebGPU (the rifle pass draws whatever pose it is given), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-03-trenchline-shots-design.md` §2.

## Global Constraints

The spec's §2 values, verbatim. They live in a new `[handling]` table unless noted.
- **Bob:** up and down 0.008 m at the stride's phase, across 0.006 m at half of it, roll 0.8°, × speedRatio; aimed × 0.15; sprint × 1.8.
- **Look sway:** 0.00012 m per °/s (aside and up) and 0.004° of roll per °/s, held to 0.025 m and 4°; a spring settling over 0.18 s at damping 0.7; aimed × 0.25.
- **Breathing:** 0.0025 m at 0.22 Hz up and down, and 0.0015 m at 0.11 Hz aside; aimed × 0.35; none at a run.
- **Sprint pose:** offset (0.06, −0.06, −0.04) m, pitch −18°, yaw 32°, roll 18°. It comes in over 0.18 s and leaves over 0.12 s. Firing or aiming drops the sprint, and no shot leaves while the blend is ≥ 0.3.
- **Landing:** 0.03 m and −4°, × min(1, landingImpact / 8), settling over 0.25 s.
- **Reload curves** (phase 0–1 of the reload; offsets in metres, angles in degrees):
  - **Long guns:**
    - 0.12 tilt: roll 28, pitch 8, offset (−0.02, −0.04, −0.03);
    - 0.28 mag out: a jolt 0.015 m down (cue `mag-out`);
    - 0.55 hold;
    - 0.62 mag in: a jolt 0.02 m up and +3° pitch (cue `mag-in`);
    - 0.82 bolt: 0.02 m back, roll 34 (cue `bolt`);
    - 1.0 rest.
  - **The M249:** the same × 1.3, with the cue `cover` at 0.45.
  - **Pistols:** tilt 18; `mag-out` at 0.3, `mag-in` at 0.62, `bolt` (the slide) at 0.86.
  - **The M870:**
    - reload time `reload_base_s` 0.5 + `reload_per_round_s` 0.5 × shells missing, in `[weapon.m870]` replacing `reload_time_s`;
    - a push of 0.02 m and +6° per shell, evenly spaced over the time after the base (cue `shell`);
    - **pump:** from 0.12 s after a shot, 0.035 m back over 0.12 s and forward over 0.12 s (cue `pump`).
- **Empty:** a trigger pressed on an empty magazine gives the `dry` cue once a press, and a reload begins 0.25 s later (`dry_reload_s`).
- **The flash:**
  - a core billboard 0.10–0.16 m across, emissive, for `flash_s`;
  - 3–5 prongs (`[effects] flash_prongs = [3, 5]`), lengths 0.15–0.30 m, each at its own roll;
  - a compensator: 2 short side prongs instead (0.08–0.12 m);
  - a suppressor: as today;
  - all drawn from a hash of the shot (its tick and the muzzle's position);
  - the light unchanged (intensity 3, radius 6 m).
- **Smoke:** `[particles.muzzle_smoke]`:
  - life 1.4 s, gravity +0.25 (it rises), drag 1.5;
  - size 0.05 → 0.35;
  - colour `[0.55, 0.55, 0.55, 0.18]` → alpha 0, lit (not emissive);
  - count 1 (2 with a suppressor), speed 0.6 along the bore, spread 0.4.
  - It drifts on the battle's wind: `Particles.wind`, a velocity added to non-emissive, non-anchored particles, set each frame from `battle/wind.ts`.
- **Pure code:** `src/combat` and `src/sim` follow `tests/architecture.test.ts`. They use dmath; any time is the tick's.
- **Commits:** branch `shots`, never pushed. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Quiet e2e only.

## Review Focus

- **The firing step's raise and the aim together:** today's `raised` and `aimed` blends must still give exactly today's pose at rest. That means no bob or breathing when still, no sway when the view is still, and no reload. Then `rifle.spec` and `loadout.spec`'s model-trace tests keep their numbers. Task 1 pins `heldPose` with a zero handling delta.
- **The scope aimed:** the scope hides the gun (≥ 0.85 aimed), but breathing still moves the drawn gun under the HUD's reticle. Aimed breathing is × 0.35 and must never move the round (rounds leave from the eye). Task 2 asserts it.
- **A reload cut short** by putting the gun away (`cancelReload`) mid-phase: the curve must ease back to rest from where it was, not snap. The shotgun's shells loaded so far are not kept (the magazine fills at the end, as today), so nothing is half-counted. Task 2 tests it.
- **Sprint and fire held together from a standstill:** the player must not sprint at all while fire is held. Today's ADS rule (`aimed > 0.5` drops the sprint) is extended to fire, and the first shot leaves within 0.12 s of the press out of a full sprint. Task 2 tests it.
- **High frame rates:** handling is ticked at 60 Hz and interpolated, so a 240 Hz display must not show the sway stepping. Task 3's e2e test at E2E_FPS unset checks that the rifle's pose changes smoothly between ticks: no two consecutive frames are identical while turning.

**Interfaces:**
- Produces:
```ts
export interface HandsDelta { offset: [number, number, number]; pitch: number; yaw: number; roll: number }
export const ZERO_HANDS: HandsDelta;
export interface HandlingTunables { /* [handling] */ }
export function handlingTunables(tun: Tunables): HandlingTunables;
export type HandlingCue = 'mag-out' | 'mag-in' | 'bolt' | 'cover' | 'shell' | 'pump' | 'dry';
export type GunClass = 'long' | 'mg' | 'pistol' | 'pump';
export interface HandlingInput {
  dt: number; time: number;            // the tick's length and the session's time (s)
  yawRate: number; pitchRate: number;  // °/s, this tick's turn of the view
  speedRatio: number; bobPhase: number; onGround: boolean; landingImpact: number;
  sprinting: boolean; aimed: number;   // 0..1
  reload: { phase: number; shells: number } | null; // shells: the shotgun's to load this reload
  sinceShot: number;                   // s since the last shot
  gun: GunClass;
}
export class Handling {
  constructor(t: HandlingTunables);
  /** One tick: the delta now, the sprint blend, and the cues crossed this tick (a curve's marks passed between its last phase and this). */
  tick(i: HandlingInput): { delta: HandsDelta; sprint: number; cues: HandlingCue[] };
  /** The delta between the last two ticks, `alpha` of the way. */
  at(alpha: number): HandsDelta;
  get sprint(): number;
}
export function gunClass(key: GunKey): GunClass;
```
